# プリン買いにいこ！

画像1の小悪魔「リリー」を主役にした、準備と横スクロールのおでかけゲーム。

- 09:00–18:00は実時間270秒。別タブでも時計が進む。
- やる気スイッチで起床、髪、着替え、出発。歯みがきは起床後に自動で開始。11時自動起床、16時以降は出現頻度と表示時間が増加。
- 二度寝は起床だけ取り消し。配信の脱線は自動終了。準備済み項目は維持。
- 移動: ← → / A D、ジャンプ: Space / ↑ / W。タッチボタンにも対応。
- 衝突は4分消費して安全なチェックポイントへ。18時より前に店舗へ到着すると購入成功。

開発: `npm run dev`。静的ビルド: `npm run build`。GitHub Pages用ビルド: `npm run build:pages`。ロジック検証: `npm test`。

GitHub Pagesでは `.github/workflows/deploy-pages.yml` がmainブランチへの更新を自動公開します。リポジトリの Settings → Pages → Source は「GitHub Actions」を選択してください。この配布物はリポジトリ名 `liligame` 用です。

人物の元資料はユーザー提供。背景2枚と8ポーズのスプライトは、その資料をもとにImageGenで制作。ニュートラル背景のスプライトシートは描画時に境界接続する色キーを透過処理。

検証: 型チェック、14件のロジックテストと7件の入力テスト（20通りの夕方開始からクリアまでのシミュレーションを含む）、WebMCPの状態取得・開始・不正入力・進行中再開始拒否を実環境で確認。ブラウザの目視・操作テストは未実施。

スマホ向け: セーフエリア対応、縦横それぞれの画面高に合うプレイ領域、移動とジャンプの同時タッチ、短いジャンプタップの保持、出現中は動かないやる気スイッチ。背景とキャラクター画像はWebPを配信し、描画はタッチ端末で最大30fps。リリーのセリフは「のじゃ」口調。
